According to a document from 2026-05-09，当前项目已经不是“继续证明 diffusion 有效”，而是进入更明确的二阶段： **以 CoDriveThesis formal suite 为主场，在强 baseline 之上继续压榨 latent-space 少步生成式 Student 的性能、鲁棒性和实时性，同时用 action-space / chunk 分支做边界探索** 。当前 formal suite 已完成 main eval、NFE/latency、representation eval、robustness 和 validation，主任务为 `Dexh13HoraLightbulbSim2RealTwoFingerCoDriveThesis`，固定步长 2048、eval seeds 42/43/44、formal train seeds 42/43/44。

## 1. 当前项目事实：下一轮优化应该从哪里切入

当前贡献边界要守住：已有 Isaac Gym Teacher-Student 框架和 PPO privileged Teacher 不是本轮优化对象；当前 Student 是 ProprioAdapt-style imitation-distillation，不是第二阶段 RL，也不是 Pure BC。后续重点应继续落在  **Student 蒸馏阶段的 diffusion-style 替换、baseline 对比和统一评测** 。

现有方法结构也已经清楚：PAdapt、Pure BC、Diffusion Latent、Consistency Latent、Flow Matching Latent、Action-Chunk Diffusion 都位于 Student 蒸馏阶段；差异主要在 Student 侧 latent 或 action 的生成方式与训练目标。 PAdapt 的监督目标是 latent loss + action BC，不能写成 Pure BC；Pure BC 是去掉 latent loss 的 BC-only 消融。 Diffusion Latent 是条件 latent diffusion，仍通过冻结 actor 输出动作；Consistency 和 Flow 则分别以 one/few-step consistency mapping 和 latent velocity field 替换确定性 adapter。

当前结果给出的方向很明确：Consistency Latent 5.228、Flow Matching 5.102，均超过 PAdapt 4.880 和 PureBC 4.817；普通 Diffusion Latent 4.569，没有超过强 baseline；Teacher PPO 5.479 仍是 fixed-step reward 口径上的参考上界。 NFE/latency 结果显示 Flow 和 Consistency 在 NFE=1 就很强，普通 Diffusion Latent 需要更多步数但 NFE=10 仍弱于 Flow/Consistency，Action-Chunk 在 NFE 网格下整体为负 reward。 Action-Chunk len=8 为 -1.232，len=1 仅 0.141，说明高维 action chunk 目前不适合作为主方法。 鲁棒性上，Consistency / Flow 多数扰动优于 PAdapt / PureBC，但 `obs4x` 对所有方法伤害明显，`initpos_noise` 下 Teacher 下降需要谨慎解释。

科研趋势也支持这个判断。Consistency Policy 的核心动机就是把 Diffusion Policy 蒸馏成低延迟策略，并报告相对最快替代方法有数量级推理加速，同时保持竞争成功率。 One-Step Diffusion Policy 也明确指出迭代去噪慢是机器人实时控制挑战，并提出单步动作生成器，报告动作预测频率从 1.5 Hz 提升到 62 Hz。 2025–2026 年的新工作则进一步把注意力转到 contact-rich reactivity：Reactive Diffusion Policy 用慢 latent diffusion 生成高层 chunk、快 tokenizer 做高频触觉反馈控制；Tube Diffusion Policy 也强调 action chunk 在接触任务中响应最新观测受限，并引入反馈 flow / action tube 来做快速修正。 对 action chunk，Real-Time Chunking 指出 chunk 提供时间一致性但不完全解决延迟，会导致 chunk 边界暂停或 OOD 抖动，因此采用边执行当前 chunk 边生成下一 chunk 的异步 inpainting；REMAC 进一步把问题拆成 inter-chunk discontinuity 和 intra-chunk inconsistency。 Latent Action Diffusion 则从另一个角度说明，把不同动作空间统一到 latent action space 能缓解高维/跨 embodiment action 建模困难。

## 3. 推荐的算法优化方向

### 方向 A：Residual Flow / Consistency over PAdapt

这是我建议第一优先级做的方向。当前 Consistency / Flow 已经强，PAdapt 也是强 baseline，所以不要完全从噪声生成 latent，而是让生成模型只学习  **PAdapt latent 到 Teacher latent 的残差修正** ：

核心假设：PAdapt 已经学到稳定接触控制的主流形，生成式模型只负责补偿隐藏接触状态和扰动恢复。这样能降低绝对 latent 生成难度，也能减少采样误差。验收条件是：NFE=1 或 2 下 reward ≥5.30，obs2x/friction/masscom 不低于当前 Flow，action jerk 不高于 PAdapt 10%。

### 方向 D：Reactive Action-Chunk，而不是普通 Action-Chunk

当前 Action-Chunk len8 失败，不建议继续只调 chunk_len 或 NFE。要改就按“reactive chunk”改：生成 chunk，但每一步执行前允许用最新 `obs/proprio_hist` 做 lightweight correction。

这与 RDP/TDP 的 slow-fast / feedback-flow 方向一致：慢策略负责复杂轨迹，快模块负责接触反馈下的快速修正。 这里的验收不要直接要求超过 Flow；先要求 Action-Chunk 从负 reward 拉到 PAdapt 的 70% 以上，即 reward ≥3.4，done rate 显著下降，再考虑主方法竞争。

### 方向 E：Latent action autoencoder / compact action manifold

如果允许从零创建新场景或新模块，可以先做 action latent autoencoder：把 teacher action 或 action chunk 编码成低维 latent，再对 latent 做 flow/consistency，最后 decode 成 action。这样吸收 Latent Action Diffusion 的思想，避免直接在原始高维动作片段上扩散。

## 9. 推荐的第一轮执行顺序

第一轮不要同时开太多分支。建议按下面顺序：

1. **先跑现有 baseline sanity check** ：确认当前脚本还能复现实验表中的 PAdapt、Consistency、Flow、Diffusion Latent 的相对排序。
2. **实现 Residual Flow over PAdapt** ：这是最可能在现有强结果上继续提升的方向。
3. **做 NFE=1/2/4 快速评估** ：如果 NFE=1 已经低于 PAdapt，就立刻分析 gate / anchor / residual norm，不要直接跑完整 formal suite。
4. **加入 robustness-aware loss** ：仅在 residual 版本 nominal 不退化后再加。
5. **再开 Reactive Action-Chunk sandbox** ：作为边界探索，不要抢主线 GPU 预算。
6. **最后做 formal acceptance** ：3 train seeds × 3 eval seeds + NFE/latency + robustness + manifest。

## 10. 最后给 CodeAgent 的边界总结

本轮优化不要追求“diffusion 全面胜利”。项目当前最可靠的结论是： **latent-space + few-step generation 有效，普通多步 diffusion 和 action chunk 暴露边界** 。下一轮真正有价值的结果有三种：

第一，Residual / Robustness-aware Flow 或 Consistency 把 reward 从 5.23 推到 5.30+，同时保持 NFE≤2 和多数扰动优势。

第二，普通 Diffusion Latent 通过 residual、one-step distillation 或 noise curriculum 追上 PAdapt，说明“多步 diffusion 弱”不是必然。

第三，Reactive Action-Chunk 从负 reward 提升到可用水平，证明 action-space 方向需要闭环修正，而不是直接否定 action diffusion。

最优先交付应是第一种；第二种可以作为机制解释；第三种作为探索性 ablation。
